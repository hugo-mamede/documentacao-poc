# Configurar formulário

Este guia apresenta um procedimento fictício
de configuração de formulários.

## Procedimento

1. Aceder à área de **Administração**;
2. Selecionar **Formulários**;
3. Criar um novo formulário;
4. Definir os campos obrigatórios;
5. Guardar a configuração.

## Resultado

O formulário fica disponível para utilização.
