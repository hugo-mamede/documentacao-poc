# Criar pedido

Esta página demonstra a estrutura de um procedimento.

## Procedimento

1. Aceder ao Atendimento Online;
2. Selecionar **Novo pedido**;
3. Preencher os campos obrigatórios;
4. Confirmar os dados;
5. Submeter o pedido.

## Resultado

O pedido fica registado no sistema.
